## Step 1: local authorization server in Python (works)

**SDK facts (read in source):**
- `mcp/server/auth/provider.py`:
  - `OAuthAuthorizationServerProvider` protocol: `get_client`, `register_client`, `authorize`, `load_authorization_code`, `exchange_authorization_code`, refresh, `load_access_token`, `revoke_token`.
  - `AuthorizationParams.resource` and `AuthorizationCode.resource` carry RFC 8707.
  - `TokenVerifier.verify_token(token) -> AccessToken | None`; `AccessToken.resource` is what the bearer middleware compares.
  - `construct_redirect_uri` helper.
- `mcp/server/auth/routes.py`:
  - `create_auth_routes(provider, issuer_url, ..., client_registration_options=...)` serves `/.well-known/oauth-authorization-server`, `/authorize`, `/token` and (when enabled) `/register`.
  - `validate_issuer_url` allows `http` only for `localhost`, `127.0.0.1` and `[::1]`.
  - `build_metadata` never sets `client_id_metadata_document_supported`.
- `mcp/server/auth/settings.py`: `AuthSettings(issuer_url, resource_server_url, required_scopes, validate_token_resource)`. Leaving `validate_token_resource` unset warns and behaves as False.
- `mcp/server/auth/middleware/bearer_auth.py`:
  - `BearerAuthBackend` rejects a token unless `AccessToken.resource` equals `resource_server_url` (URL-normalised, trailing slash ignored). The request then has no user, so the response is 401.
  - `RequireAuthMiddleware` returns 401 `invalid_token` or 403 `insufficient_scope`, with `WWW-Authenticate: Bearer error=..., error_description=..., resource_metadata="..."`.
- `mcp/server/mcpserver/server.py`:
  - `MCPServer(auth=..., token_verifier=...)` or `auth_server_provider=...` (not both).
  - It serves PRM at `/.well-known/oauth-protected-resource/mcp` (`create_protected_resource_routes`) with `authorization_servers=[issuer_url]` and `scopes_supported=required_scopes`.
- `mcp/server/auth/handlers/token.py`:
  - The token endpoint checks PKCE S256 and that `redirect_uri` is unchanged. It does **not** compare the token request's `resource` with the code's `resource`, and the provider never sees the token request's `resource`.
  - So the AS must bind `aud` to the `resource` given at `/authorize` (`AuthorizationCode.resource`).

**Architecture:** the AS is separate from the resource server. It is a Starlette app on `127.0.0.1:9000` built from the SDK's routes. The SDK also lets `MCPServer(auth_server_provider=...)` co-host the AS, but separation is what the spec models and what the Go RS needs.

**The resource server** (`ops_rs.py`):

```python
RESOURCE = "http://127.0.0.1:8766/mcp"

class JWTVerifier:
    async def verify_token(self, token: str) -> AccessToken | None:
        try:
            c = jwt.decode(token, SECRET, algorithms=["HS256"], issuer=ISSUER,
                           options={"verify_aud": False, "require": ["exp", "iss", "aud"]}, leeway=30)  # exp/nbf/iat checked by PyJWT
        except jwt.PyJWTError:
            return None
        aud = c["aud"]  # RFC 7519: a string or a list; report the entry naming this server, if any
        resource = RESOURCE if isinstance(aud, list) and RESOURCE in aud else (aud if isinstance(aud, str) else None)
        return AccessToken(token=token, client_id=c["client_id"], scopes=c.get("scope", "").split(),
                           expires_at=c["exp"], resource=resource, subject=c.get("sub"), claims={"iss": c["iss"]})

mcp = MCPServer("lumen-ops-spike", token_verifier=JWTVerifier(), auth=AuthSettings(
    issuer_url="http://127.0.0.1:9000", resource_server_url="http://127.0.0.1:8766/mcp",
    required_scopes=["tickets:write"], validate_token_resource=True))
uvicorn.run(mcp.streamable_http_app(host="127.0.0.1"), host="127.0.0.1", port=8766)
# inside a tool: from mcp.server.auth.middleware.auth_context import get_access_token; get_access_token().client_id
```

PyJWT verifies `exp`, `nbf` and `iat` by default (here with 30 s leeway). The fix-round run gave: `aud` list including the resource 200, list without it 401, expired 401, `nbf` in the future 401.

`verify_aud=False` is deliberate. The verifier reports `aud` as `AccessToken.resource`, and the SDK's `validate_token_resource=True` enforces it. Do not check `aud` in both places, because a duplicate check hides which layer did the work.

**Client registration:**
- **Pre-registered: works.** It is shown above. The client skips registration when `TokenStorage.get_client_info()` returns the client.
- **DCR: works.** With empty storage, the client POSTed `/register` and got a UUID `client_id`. The rest of the flow was identical (`whoami: client=d9123793-...`). Registration needs `ClientRegistrationOptions(enabled=True, ...)`. DCR is deprecated in 2026-07-28.
- **CIMD: not supported out of the box.**
  - Evidence 1: `build_metadata` never advertises `client_id_metadata_document_supported`. So `OAuthClientProvider(..., client_metadata_url="https://lumen.example/oauth/client.json")` silently **fell back to DCR** in the run (`client_id used: 79e88231-...`). Source: `mcp/client/auth/utils.py:should_use_client_metadata_url`.
  - Evidence 2: the SDK client rejects non-HTTPS CIMD URLs: `ValueError: client_metadata_url must be a valid HTTPS URL with a non-root pathname, got: http://127.0.0.1:9100/client.json` (`is_valid_client_metadata_url`). A local, http-only course setup therefore cannot host a real client document.
  - Evidence 3 (`cimd_probe.py`): the SDK's AS pipeline *can* carry a URL client id if we add CIMD ourselves. We prepended our own `/.well-known/oauth-authorization-server` route with `client_id_metadata_document_supported: true`, and wrote a `get_client` that resolves `https://` client ids. The document fetch was a **stub dict**, because no local HTTPS host exists. With that, the full flow worked: `client_id used: https://lumen.example/oauth/client.json`, 200 with the flow token, and 401/403 as above. This was not a real CIMD fetch.
- **Ruling:**
  - `auth_server.py` uses a **pre-registered public client** `lumen-cli`, with redirect `http://127.0.0.1:33418/callback`, `token_endpoint_auth_method="none"` and PKCE.
  - DCR stays enabled.
  - Lesson 9 explains that CIMD is preferred, and that it needs an HTTPS client document that our loopback-only lab cannot serve.
  - Auth is never dropped.

**`http://127.0.0.1` resource URIs:**
- **Accepted**: the AS issuer, the PRM `resource`, the `resource` parameter and the token `aud` all used `http://127.0.0.1:...` with no errors or warnings.
- Redirect URIs are matched exactly, including the port, so use a fixed callback port (`OAuthClientInformationFull.validate_redirect_uri`).

**Other observations:**
- RFC 9207 `iss` is validated by the client. A wrong `iss` in the redirect failed with `OAuthFlowError: Authorization response iss mismatch` (seen during the probe), so the AS must stamp its own issuer.
- Python's 401/403 `WWW-Authenticate` has no `scope="..."` parameter, and Go's has no `error=` parameter. Tests should assert only `resource_metadata=`.

## Step 2: Go resource server (works, with HTTP hardening)

**SDK facts (read in source):**
- `auth/auth.go`:
  - `RequireBearerToken(verifier, &RequireBearerTokenOptions{ResourceMetadataURL, Scopes})`.
  - A verifier error that wraps `auth.ErrInvalidToken` gives 401. A missing scope gives 403 `insufficient scope`. A zero `Expiration` gives 401 unless `AllowMissingExpiration`.
  - **There is no audience check in the middleware** (ruling R7).
  - The middleware checks scopes *before* expiry, so the verifier itself checks `exp`/`nbf`/`iat`. That makes an expired token 401, not 403.
  - `WWW-Authenticate: Bearer resource_metadata="...", scope="..."` goes on both 401 and 403. It has no `error=` parameter.
  - `ProtectedResourceMetadataHandler(&oauthex.ProtectedResourceMetadata{...})` serves the PRM.
- `oauthex/audience.go`: `MatchesResource(claims, resource)` compares exactly, except that a trailing slash is ignored.
- `mcp/shared.go`: tools read the token via `req.Extra.TokenInfo`.
- `mcp/streamable.go`:
  - `StreamableHTTPOptions.CrossOriginProtection` is **Deprecated** in v1.8.0, and the comment says to wrap the handler instead.
  - `MaxRequestBodyBytes` exists and gives 413.
  - The handler also rejects a non-loopback `Host` on a loopback listener with 403 (`DisableLocalhostProtection` turns that off).
- Go standard library: `http.NewCrossOriginProtection()` rejects non-safe requests whose `Origin` host differs from `Host`, with 403. It also uses `Sec-Fetch-Site`. Requests with no `Origin` and no `Sec-Fetch-Site` are allowed (non-browser clients). `AddTrustedOrigin` allows named extra origins.

The token is an HS256 JWT checked with the standard library. go-sdk v1.8.0 has no JWT dependency, and the course adds none.

**Complete, run code** (`go/ops/main.go`, sections 1 and 4; section 3 is in Step 4):

```go
const (
	issuer   = "http://127.0.0.1:9000"
	resource = "http://127.0.0.1:8767/mcp"
	// jwtKey: no literal. Load it with auth.LoadSigningKey() from mcp/data/dev-signing.key (R25; redacted)
	maxBody  = 131072
)

// ── 1. Token verifier: signature, iss, exp/nbf/iat, aud (string or list) ──
func b64json(seg string, v any) error {
	b, err := base64.RawURLEncoding.DecodeString(seg)
	if err != nil {
		return err
	}
	return json.Unmarshal(b, v)
}

func verifyJWT(_ context.Context, token string, _ *http.Request) (*auth.TokenInfo, error) {
	p := strings.Split(token, ".")
	if len(p) != 3 {
		return nil, auth.ErrInvalidToken
	}
	var hdr struct {
		Alg string `json:"alg"`
	}
	if b64json(p[0], &hdr) != nil || hdr.Alg != "HS256" {
		return nil, auth.ErrInvalidToken
	}
	mac := hmac.New(sha256.New, jwtKey) // jwtKey []byte from auth.LoadSigningKey()
	mac.Write([]byte(p[0] + "." + p[1]))
	sig, err := base64.RawURLEncoding.DecodeString(p[2])
	if err != nil || !hmac.Equal(sig, mac.Sum(nil)) {
		return nil, auth.ErrInvalidToken
	}
	var c struct {
		Iss      string          `json:"iss"`
		Aud      json.RawMessage `json:"aud"`
		Sub      string          `json:"sub"`
		ClientID string          `json:"client_id"`
		Scope    string          `json:"scope"`
		Exp      int64           `json:"exp"`
		Nbf      int64           `json:"nbf"`
		Iat      int64           `json:"iat"`
	}
	if b64json(p[1], &c) != nil || c.Iss != issuer || c.Sub == "" || c.ClientID == "" {
		return nil, auth.ErrInvalidToken
	}
	now, skew := time.Now().Unix(), int64(30)
	if c.Exp == 0 || now > c.Exp+skew || (c.Nbf != 0 && now+skew < c.Nbf) || (c.Iat != 0 && now+skew < c.Iat) {
		return nil, fmt.Errorf("%w: expired or not yet valid", auth.ErrInvalidToken) // 401 before the scope check
	}
	var auds []string // RFC 7519: aud is a string or an array of strings
	if json.Unmarshal(c.Aud, &auds) != nil {
		var one string
		if json.Unmarshal(c.Aud, &one) != nil {
			return nil, auth.ErrInvalidToken
		}
		auds = []string{one}
	}
	if !oauthex.MatchesResource(auds, resource) {
		return nil, fmt.Errorf("%w: audience %v", auth.ErrInvalidToken, auds)
	}
	return &auth.TokenInfo{Scopes: strings.Fields(c.Scope), Expiration: time.Unix(c.Exp, 0), UserID: c.Sub,
		Extra: map[string]any{"client_id": c.ClientID}}, nil
}

// ── 4. HTTP: Origin (403) -> body cap (413) -> bearer auth (401/403) -> MCP ──
func capBody(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.ContentLength > maxBody {
			http.Error(w, "request body too large", http.StatusRequestEntityTooLarge)
			return
		}
		r.Body = http.MaxBytesReader(w, r.Body, maxBody) // also bounds chunked bodies
		next.ServeHTTP(w, r)
	})
}

func main() {
	flag.Parse()
	server := mcp.NewServer(&mcp.Implementation{Name: "lumen-ops-go-spike", Version: "0.0.1"}, nil)
	mcp.AddTool(server, &mcp.Tool{Name: "label_ticket", Description: "Label a ticket (asks the user to confirm)."}, labelTicket)
	mcpHandler := mcp.NewStreamableHTTPHandler(func(*http.Request) *mcp.Server { return server },
		&mcp.StreamableHTTPOptions{Stateless: true, MaxRequestBodyBytes: maxBody})
	protect := auth.RequireBearerToken(verifyJWT, &auth.RequireBearerTokenOptions{
		ResourceMetadataURL: "http://127.0.0.1:8767/.well-known/oauth-protected-resource/mcp",
		Scopes:              []string{"tickets:write"},
	})
	cop := http.NewCrossOriginProtection() // Origin host must equal Host, else 403
	for _, o := range []string{"http://127.0.0.1:6274", "http://localhost:6274"} { // Inspector web UI
		if err := cop.AddTrustedOrigin(o); err != nil {
			log.Fatal(err)
		}
	}
	mux := http.NewServeMux()
	mux.Handle("/.well-known/oauth-protected-resource/mcp", auth.ProtectedResourceMetadataHandler(
		&oauthex.ProtectedResourceMetadata{Resource: resource, AuthorizationServers: []string{issuer},
			ScopesSupported: []string{"tickets:write"}, BearerMethodsSupported: []string{"header"}}))
	mux.Handle("/mcp", cop.Handler(capBody(protect(mcpHandler))))
	log.Fatal(http.ListenAndServe("127.0.0.1:8767", mux))
}
```

**Ordering (verified):**
- **Go**, as wired above: a bad Origin gets **403 with or without a token**, and an oversized body gets **413 with or without a token**. Origin is checked first, then the body cap, then auth.
- **Python**, with the SDK default: a bad Origin *without* a token gets **401**, because auth runs before the SDK's Origin check. With a valid token it gets 403.
- Parity rule for Task 8 tests: assert the bad-Origin 403 **with a valid token**. That holds in both languages.

**Origin parity:**
- The Python SDK allows any `http://127.0.0.1:*`, `localhost:*` or `[::1]:*` origin.
- Go's `CrossOriginProtection` allows only the server's own origin plus `AddTrustedOrigin` entries.
- The Inspector web UI (`:6274`) therefore needs `AddTrustedOrigin` in Go. That is shown above and verified.

**Notes for Task 8:**
- The shared HS256 key means anyone who holds it can mint tokens. That is acceptable only for a loopback test AS. RS256 with a JWKS is the production shape; say so in the lesson.
- The Python verifier now also normalises a list `aud` (see Step 1). It was verified on the Python RS: list including the resource gives 200, list without it gives 401, expired gives 401, `nbf` in the future gives 401.

## Step 4: elicitation round trip (works in Python and Go)

**What confirmation proves.** In both SDKs, the elicitation answer is **asserted by the client**. The server cannot tell whether a human clicked "accept" or whether client code answered for them.
- The signed or sealed `requestState` proves only that the retry came from the **same caller** (token subject/client), for the **same request** (same tool and arguments), **within a short time**, and that the server issued it.
- Lesson 8 must say this plainly. Confirmation is a host-side UX safeguard, and provenance (`source`, `client_id`, `confirmed`) records what was claimed. It is not proof of human intent.

### Python: the `Resolve` + `Elicit` resolver (MRTR)

**SDK facts:**
- `mcp/server/mcpserver/resolve.py`:
  - `Annotated[T, Resolve(fn)]` fills a parameter by running resolver `fn` (which may take tool arguments by name) **before** the tool body.
  - A resolver returning `Elicit(message, Model)` becomes an `elicitation/create` entry in an `InputRequiredResult` on 2026-07-28. On ≤ 2025-11-25 it becomes a standalone server-to-client request.
  - Annotating the consumer `ElicitationResult[T]` gives accept, decline and cancel to the tool body.
  - The tool body runs only on the final round, so the write happens once.
- `mcp/server/elicitation.py`: `AcceptedElicitation(data=...)`, `DeclinedElicitation`, `CancelledElicitation`.
- `mcp/server/request_state.py`:
  - `RequestStateSecurity(ttl=600.0, bind_principal=authenticated_principal, audience=None)` is the default (`ephemeral()` key per process).
  - The boundary enforces expiry, request binding, audience (the server name) and principal, and fails closed.
- `Context.elicit(...)` (push-style, `mcp/server/mcpserver/context.py`) was **not tested**. Use the resolver.

**Errors (ruling R5):**
- `raise ToolError(msg)`, raised either in the tool or in a resolver, comes back prefixed: `'Error executing tool label_ticket: …'`. That was verified for both the decline text and the bad-label text.
- So the recipe never raises. It returns `CallToolResult(is_error=True)` with the fixed text.
- Because resolvers run before the body, the bad label is screened in the resolver. The resolver returns `DeclinedElicitation()` without asking, then the body checks the label first and returns the fixed label error.

**Complete, run recipe** (`step4_label_recipe.py`):

```python
LABELS = ["billing", "bug", "account", "how_to", "feature_request", "outage"]
BAD_LABEL = "label must be one of: " + ", ".join(LABELS)
DECLINED = "label not written: the user declined"
OUT = "labels_py.jsonl"
_lock = threading.Lock()


class Confirm(BaseModel):
    confirm: bool


def ask_confirm(id: str, label: str) -> Elicit[Confirm] | DeclinedElicitation:
    """Resolver. An invalid label is never put to the user: no question, the tool body rejects it."""
    if label not in LABELS:
        return DeclinedElicitation()
    return Elicit(f"Write label '{label}' on ticket {id}?", Confirm)


def error(text: str) -> CallToolResult:
    return CallToolResult(content=[TextContent(type="text", text=text)], is_error=True)


def label_ticket(id: str, label: str,
                 answer: Annotated[ElicitationResult[Confirm], Resolve(ask_confirm)]) -> CallToolResult:
    if label not in LABELS:                                   # checked first, so the fixed text wins
        return error(BAD_LABEL)
    if answer.action != "accept" or not answer.data.confirm:
        return error(DECLINED)
    tok = get_access_token()                                  # None in-memory (no HTTP auth)
    row = {"ticket_id": id, "label": label, "source": "agent", "client_id": tok.client_id if tok else None,
           "model": None, "confirmed": True, "time": datetime.now(timezone.utc).isoformat()}
    with _lock, open(OUT, "a", encoding="utf-8") as f:       # one full line per write, under a lock
        f.write(json.dumps(row) + "\n")
    return CallToolResult(content=[TextContent(type="text", text=f"labelled {id} as {label}")])

# registered with mcp.tool()(label_ticket) (or @apps.tool(...) for lumen-ops), on the Step 1 auth server
```

Imports: `get_access_token` from `mcp.server.auth.middleware.auth_context`, `DeclinedElicitation` and `ElicitationResult` from `mcp.server.elicitation`, `Elicit` and `Resolve` from `mcp.server.mcpserver.resolve`, and `CallToolResult` and `TextContent` from `mcp_types`.

**Client:** `Client(..., elicitation_callback=cb)`. Declaring the callback is what declares the `elicitation.form` capability. The `Client` drives the retry rounds automatically.

```python

    return ElicitResult(action="accept", content={"confirm": True})   # or ElicitResult(action="decline")
```

### Go: `InputRequiredResult` by hand, with signed `RequestState`

**SDK facts:**
- `mcp/protocol.go`:
  - `CallToolResult.InputRequests` (`InputRequestMap`, values like `*mcp.ElicitParams`) and `CallToolResult.RequestState`.
  - The retry arrives as `req.Params.InputResponses` (values `*mcp.ElicitResult`) and `req.Params.RequestState`.
  - The doc comment says servers must encrypt, sign and verify `RequestState`.
- `mcp/mrtr.go`:
  - The server sets `resultType: input_required` for 2026-07-28 clients.
  - The client middleware fulfils requests through `ClientOptions.ElicitationHandler`, up to 10 rounds.
- There is no `Elicit`-style helper.

**Complete, run code** (`go/ops/main.go`, sections 2 and 3):

```go
var (
	labels   = []string{"billing", "bug", "account", "how_to", "feature_request", "outage"}
	stateKey = []byte("spike-request-state-key-32-bytes!!") // server-only key; never sent to clients
	stateTTL = flag.Duration("state-ttl", 5*time.Minute, "how long a confirmation round may take")
	outPath  = flag.String("out", "labels.jsonl", "append-only label rows")
	writeMu  sync.Mutex
)

// ── 2. RequestState: HMAC over caller + request + issued-at ──
type confirmState struct {
	Sub, ClientID, ID, Label string
	Iat                      int64
}

func signState(s confirmState) string {
	payload, _ := json.Marshal(s)
	m := hmac.New(sha256.New, stateKey)
	m.Write(payload)
	return base64.RawURLEncoding.EncodeToString(payload) + "." + base64.RawURLEncoding.EncodeToString(m.Sum(nil))
}

// verifyState: same key, same caller (sub+client), same arguments, younger than stateTTL.
func verifyState(raw string, want confirmState) bool {
	p := strings.Split(raw, ".")
	if len(p) != 2 {
		return false
	}
	payload, err1 := base64.RawURLEncoding.DecodeString(p[0])
	sig, err2 := base64.RawURLEncoding.DecodeString(p[1])
	if err1 != nil || err2 != nil {
		return false
	}
	m := hmac.New(sha256.New, stateKey)
	m.Write(payload)
	if !hmac.Equal(sig, m.Sum(nil)) {
		return false
	}
	var got confirmState
	if json.Unmarshal(payload, &got) != nil {
		return false
	}
	age := time.Since(time.Unix(got.Iat, 0))
	return got.Sub == want.Sub && got.ClientID == want.ClientID && got.ID == want.ID && got.Label == want.Label &&
		age >= 0 && age <= *stateTTL
}

// ── 3. label_ticket ──
type LabelIn struct {
	ID    string `json:"id"`
	Label string `json:"label"`
}

func text(s string, isErr bool) *mcp.CallToolResult {
	return &mcp.CallToolResult{Content: []mcp.Content{&mcp.TextContent{Text: s}}, IsError: isErr}
}

const declined = "label not written: the user declined"

func labelTicket(ctx context.Context, req *mcp.CallToolRequest, in LabelIn) (*mcp.CallToolResult, any, error) {
	if !slices.Contains(labels, in.Label) { // validate before asking
		return text("label must be one of: "+strings.Join(labels, ", "), true), nil, nil
	}
	ti := req.Extra.TokenInfo
	want := confirmState{Sub: ti.UserID, ClientID: ti.Extra["client_id"].(string), ID: in.ID, Label: in.Label}
	resp, ok := req.Params.InputResponses["confirm"]
	if !ok { // round 1: ask
		want.Iat = time.Now().Unix()
		return &mcp.CallToolResult{
			InputRequests: mcp.InputRequestMap{"confirm": &mcp.ElicitParams{Mode: "form",
				Message: fmt.Sprintf("Write label '%s' on ticket %s?", in.Label, in.ID),
				RequestedSchema: map[string]any{"type": "object",
					"properties": map[string]any{"confirm": map[string]any{"type": "boolean"}},
					"required":   []string{"confirm"}}}},
			RequestState: signState(want),
		}, nil, nil
	}
	if !verifyState(req.Params.RequestState, want) { // round 2: fail closed on any mismatch
		return text(declined, true), nil, nil
	}
	er, _ := resp.(*mcp.ElicitResult)
	if er == nil || er.Action != "accept" || er.Content["confirm"] != true {
		return text(declined, true), nil, nil
	}
	row, _ := json.Marshal(map[string]any{"ticket_id": in.ID, "label": in.Label, "source": "agent",
		"client_id": want.ClientID, "model": nil, "confirmed": true, "time": time.Now().UTC().Format(time.RFC3339)})
	writeMu.Lock() // one Write of one full line under a lock: rows never interleave
	defer writeMu.Unlock()
	f, err := os.OpenFile(*outPath, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)
	if err != nil {
		return nil, nil, err
	}
	defer f.Close()
	if _, err := f.Write(append(row, '\n')); err != nil {
		return nil, nil, err
	}
	return text(fmt.Sprintf("labelled %s as %s", in.ID, in.Label), false), nil, nil
}
```

`labelTicket` relies on `RequireBearerToken` running first: `req.Extra.TokenInfo` is non-nil on this server. A server without auth would need a nil check.

## Other verified facts
